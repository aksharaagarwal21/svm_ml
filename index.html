    Any Road

    Every day, computers sort things into groups.

    This is called Classification.

    Today we'll learn one of the smartest ways to do it: Support Vector Machine (SVM).

    Each dot is one student.

    Features = what we measure (hours studied, classes attended).

    Label = the answer we already know (Pass or Fail).

    The computer learns from labeled examples. This is called Supervised Learning.

    SVM finds the best line to separate two groups: the line with the widest gap between them.

    Support→ only a few points hold up (support) the line
    Vector→ each point is a vector, a list of numbers like [6, 8]
    Machine→ a method the computer follows

    Many lines can separate the groups. SVM picks the one with the widest road.

    You already know the line y = mx + c. SVM writes a line like this:

    w₁x₁ + w₂x₂ + b = 0
    x₁, x₂ = features (hours, classes)
    w₁, w₂ = weights (how important each feature is)
    b = bias (moves the line)
    Result > 0 → Pass | Result < 0 → Fail. The sign decides the group.
    Margin (road width) =2 / ‖w‖

    The points touching the dashed lines are the Support Vectors.

    Smaller ‖w‖ means a wider road.

    SVM's goal: make the road as wide as possible while keeping every point on the correct side.

    You don't need to solve this by hand. The computer does it. Let's see it in action!

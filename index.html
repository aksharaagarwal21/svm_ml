✓ Advantages

  • Works well with many features (high-dimensional data).
  • Built on a clear idea: the widest margin.
  • Kernels handle curved patterns.
  • Good on small and medium datasets.

✗ Disadvantages

  • Kernel SVMs can be slow on very large datasets.
  • Sensitive to feature scaling.
  • Kernel and settings may need tuning.
  • Curved models are hard to explain.

No algorithm is automatically best for every dataset.

Predict a New Student Outcome

SVM learns a decision boundary that separates classes while maximising the margin. The training points that determine this boundary are called support vectors, and the boundary is called a hyperplane. If a straight boundary isn't enough, SVM can use kernels to find more complex boundaries. The result is a model that can classify new data.
Key takeawaySVM doesn't simply try to separate training examples. It tries to learn a boundary that balances separation, margin size, and allowed errors, so it can make useful predictions on unseen data.

SVM is a supervised machine learning method.

This example uses study hours and attendance to predict student outcomes.

SVM finds the best line to separate two groups: the line with the widest gap between them.

Support→ only a few points hold up (support) the line

A hyperplane is the boundary SVM uses to separate groups.

1D: a point · 2D: a line · 3D: a plane · 4D+: a hyperplane.

You already know the line y = mx + c. SVM writes a line like this:

w₁x₁ + w₂x₂ + b = 0
x₁, x₂ = features (hours, classes)
w₁, w₂ = weights (how important each feature is)
b = bias (moves the line)
Result > 0 → Pass | Result < 0 → Fail. The sign decides the group.
Margin (road width) =2 / ‖w‖

The points touching the dashed lines are the Support Vectors.

Smaller ‖w‖ means a wider road.

SVM's goal: make the road as wide as possible while keeping every point on the correct side.

A bigger margin helps, but it doesn't guarantee correct predictions.

The whole SVM idea in one line: a wide road plus a penalty for margin violations.

But what if no straight road works at all?

Kernel Trick: add a new feature, like z = x² + y², to lift the points into 3D where a flat plane can separate them.

A kernel decides what shape the boundary can take.

Choose a kernel suited to the data: linear, polynomial, or RBF.

Gamma (γ) sets how far each point's circle of influence reaches (RBF kernel).

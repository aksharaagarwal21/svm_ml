# Presenter Checklist

## The day before

- [ ] Check the three names in `window.PRESENTERS` at the top of `index.html`.
- [ ] Each presenter reads their part of [`SCRIPT.md`](SCRIPT.md) out loud once.
- [ ] Open a Live Demo screen once to check that Python loads on the classroom network.

## Before class starts

- [ ] Copy `index.html` and the `live-demo` folder together onto the presenting laptop.
- [ ] Open `index.html` in Chrome or Edge and press **F** for full screen.
- [ ] Check the text is readable from the back row.
- [ ] Test the clicker: **Page Down** goes forward, **Page Up** goes back.
- [ ] Press **N** and **M** once to check the presenter notes and the chapter menu, then close them.

## During the talk

| Key | What it does |
|---|---|
| → / Space / Page Down | Next step or screen |
| ← / Page Up | Previous screen |
| Home / End | First or last screen |
| N | Show or hide presenter notes |
| M | Jump to any chapter |
| F | Full screen |
| A–C or 1–3 | Answer a quiz question |

- The first three interactive screens in Chapter 2 have a **↺ Reset** button if a demo gets messy.
- If you lose your place, press **M** and pick the screen.

## If the Live Demo can't load Python

- Click **Show saved output**. It appears after 20 seconds on a slow connection.
- Or click **Retry Python** to try loading again.
- The saved results are real outputs from the same code, so the demo still works.
